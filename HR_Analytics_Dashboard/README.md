# HR Analytics Dashboard using SQL & Power BI

## 📌 Project Overview
This project focuses on end-to-end HR analytics using SQL, Power BI, and DAX.

A real-world HR dataset from Kaggle was imported into a MySQL database and connected to Power BI using the MySQL connector. The project demonstrates data analysis, KPI reporting, dashboard creation, and business-focused visualization techniques.

The goal of this project was to analyze employee data and generate actionable HR insights through interactive dashboards.

---

# 🛠️ Tools & Technologies Used
- SQL
- MySQL
- Power BI
- DAX (Data Analysis Expressions)
- MySQL Connector
- Kaggle Dataset

---

# 📂 Workflow

## 1️⃣ Dataset Collection
- Downloaded HR analytics dataset from Kaggle
- Imported CSV dataset into MySQL database

## 2️⃣ Database Integration
- Connected Power BI to MySQL using MySQL Connector
- Loaded employee data directly from SQL database

## 3️⃣ Data Analysis
Performed analysis using:
- SQL Queries
- DAX Measures
- KPI Metrics
- Business Calculations

## 4️⃣ Dashboard Development
Built interactive HR dashboards and visualizations to analyze workforce trends and employee insights.
